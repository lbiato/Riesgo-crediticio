# Ruta Riesgo Crediticio

Práctica de SQL y Python aplicada a riesgo crediticio y cobranzas B2B, con un proyecto final de scoring.

**Datos:** cartera B2B **ficticia** (300 clientes, ~4.700 facturas, pagos, gestiones de cobranza), corte 30/09/2026. Ningún dato corresponde a empresas o personas reales.

## Contenido

- `datos/` — base SQLite `cartera_creditos.db` y los mismos datos en CSV.
- `sql/` — 10 ejercicios graduados (aging, uso de límite, comportamiento de pago, funciones de ventana) y mis soluciones.
- `python/` — los mismos análisis con pandas.
- `scoring/` — modelo de scoring: definición de default, construcción de variables, regresión logística, evaluación con AUC / Gini / KS.
